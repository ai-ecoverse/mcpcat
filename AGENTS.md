# mcpcat

`@ai-ecoverse/mcpcat`: a curl for MCP. Node ≥ 24, ESM, TypeScript in `src/`, built by esbuild into two bundles: `dist/host/mcpcat.mjs` (npm bin) and `dist/kernel/mcpcat.mjs` (slicc-kernel `abi: "js"`). Lint with `slicc-lint`. No comments in files we write. No CLAUDE.md. Unit tests in gitignored `test/unit/` with diff coverage; integration tests in `test/integration/`. semantic-release on `main` with fledgling trusted publishing. The kernel bundle is one self-contained ESM file with no imports. Platform interface in `src/platform/types.ts`; host in `host.ts`, kernel in `kernel.ts`. Spec: `docs/spec.html`. Releases are certified by `.github/workflows/cert-review.yml` (tools in `scripts/cert-review/`, security rows in `rows.json`); pinned cert kernels are `kernel-cert-*` devDependencies.
