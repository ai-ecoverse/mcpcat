# mcpcat

`@ai-ecoverse/mcpcat`: a curl for MCP. Node ≥ 26, ESM, TypeScript in `src/`, built by esbuild into two bundles: `dist/host/mcpcat.mjs` (npm bin) and `dist/kernel/mcpcat.mjs` (slicc-kernel `abi: "js"`). Lint with `slicc-lint`. No comments in files we write. No CLAUDE.md. Unit tests in gitignored `test/unit/` with diff coverage; integration tests in `test/integration/`. semantic-release on `main` with fledgling trusted publishing. The kernel bundle is one self-contained ESM file with no imports. Platform interface in `src/platform/types.ts`; host in `host.ts`, kernel in `kernel.ts`. Spec: `docs/spec.html`. CI: `ci.yml` calls slicc-shared-web's `pipeline.yml` (lint, `npm test` on Node 26, Claude and Codex review, release on `main`); its version equals the slicc-shared-web devDependency.
